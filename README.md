# Qadeer Hassan — Developer Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in your browser.

## Deploy with GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to the root of your repository.
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

Skills and technologies are separated into current foundation, exploring, and learning roadmap to avoid overstating proficiency.
